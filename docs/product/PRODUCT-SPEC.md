# WiTime 桌面时钟 产品规格书

**版本**：v0.4-demo  
**日期**：2026-10-28  
**状态**：功能验收阶段

---

## 1. 产品概述

WiTime 是一款桌面语音时钟：24 颗 WS2812 环灯显示时间，支持语音问答、整点报时、天气播报、闹钟与计时。

**定位**：家庭/办公桌面时钟，语音为主要交互方式，脱离手机也能独立工作（配网后）。

**核心卖点**：
- 语音问时间/日期/天气，无需看手机
- 整点报时（12 套提示音）
- 双闹钟 + 正计时/倒计时
- WiFi 断线自动重连，时间/天气本地缓存

## 2. 系统架构

```
┌─────────────────┐   UART 9600 8N1   ┌──────────────────┐
│  ESP32-C3       │◄─────────────────►│  ASRPRO V5.0     │
│  主控 / 联网     │  GPIO1(TX)→PA5    │  语音识别 + 播报  │
│  时间 / 闹钟     │  GPIO0(RX)←PA6    │  TF 卡 MP3 播放   │
└────────┬────────┘                   └──────────────────┘
         │
    ┌────┴────┐
    │ 24×WS2812│  GPIO3
    └─────────┘
```

**职责划分**：

| 模块 | 负责 | 不负责 |
|---|---|---|
| ESP32-C3 | 时间基准、WiFi/SNTP、天气、闹钟调度、灯环显示、计时 | 语音识别、语音合成 |
| ASRPRO | 命令词识别、片段播报、TF 卡音乐 | 时间计算、闹钟判断 |

**设计原则**：时间/闹钟只在 ESP32 侧计算。ASRPRO 的 `millis()` 会被播报阻塞，精度不可靠。

## 3. 功能矩阵

### 3.1 时间与显示

| 功能 | 说明 | 实现 |
|---|---|---|
| 时钟显示 | 24 像素环，时/分针位置 + 秒点 | `clock_display` |
| 自动校时 | 上电连 WiFi → SNTP → 时区（IP 定位） | `time_service` |
| 时区 | 自动获取 UTC 偏移（默认 +8） | `time_service` |
| 断电记忆 | WiFi 凭据/闹钟/坐标/时区存 NVS | `app_config` |

### 3.2 语音交互

| 功能 | 唤醒词 | 回复 |
|---|---|---|
| 问时间 | 小爱同学 → 现在几点/几号 | 「现在是上午九点三十三分」 |
| 问天气 | 小爱同学 → 今天天气 | 「今天杭州天气晴，气温十二到十九摄氏度」 |
| 整点报时 | 自动（每小时） | 12 套提示音 + 「现在是九点整」 |
| 开机问候 | 自动（上电 12 秒后） | 「上午好，现在时间是…，今天…天气…」 |

### 3.3 闹钟

| 项目 | 规格 |
|---|---|
| 槽位 | **2 个** |
| 设置流程 | 日期（今天/明天/每天）→ 时段（早上/上午/中午/下午/晚上/凌晨）→ 几点几分 |
| 分钟精度 | **5 分钟档位**（词表 720 条时间词） |
| 重复 | 每天 / 单次（自动顺延到明天） |
| 响铃 | TF 卡 `101.mp3` + 语音「现在时间…天气…记得按时起床哦」 |
| 停止 | 「小爱同学 → 停止」 |
| 取消 | 「取消闹钟」→ 确认 → 「全部取消」 |
| 满槽 | 播报提示并引导全部取消 |

**限制**：不支持一句话说法（如「今天下午三点的闹钟」）。ASRPRO 是整句匹配，必须按引导分步说。

### 3.4 计时

| 功能 | 命令 | 行为 |
|---|---|---|
| 正计时开始 | 开始计时 | 开始累加 |
| 正计时停止 | 停止计时 | 播报「这次计时时间为 X 分 Y 秒」 |
| 倒计时开始 | 倒计时 N 分钟 | 13 档：1/2/3/4/5/8/10/15/20/25/30/45/60 |
| 倒计时到点 | 自动 | TF 卡 `201.mp3` 响 4 秒 → 「您好，时间到了」 |
| 取消 | 取消计时 / 取消倒计时 | 播报确认 |

### 3.5 配网与状态

| 项目 | 规格 |
|---|---|
| 配网方式 | BLE BluFi（App 下发 WiFi） |
| 广播名 | `ESPARK-ECLOCK-<MAC后6位>` |
| 状态指示 | 见 §3.6 |
| BOOT 短按 | 静音 ⇄ 恢复（音量 0 ⇄ 30） |
| BOOT 长按 3 秒 | 擦除 NVS（WiFi/闹钟/坐标）并重启 |

### 3.6 灯环状态定义

| 状态 | 表现 |
|---|---|
| 正常时钟 | 时/分针 + 秒点 |
| 蓝牙广播/连接 | 蓝色（0,0,255） |
| WiFi 连接中/成功 | 绿色（0,255,0） |
| 校时中/成功 | 青色（0,255,255） |
| 网络失败 | 红色（255,0,0）呼吸 |
| 数据异常 | 橙色（255,128,0）呼吸 |
| 蓝牙超时 | 紫色（160,0,255）呼吸 |
| **模组链路断开** | **红色呼吸（持续到恢复）** |

## 4. 技术规格

### 4.1 硬件

| 项目 | 参数 |
|---|---|
| 主控 | ESP32-C3（RISC-V 单核 160 MHz） |
| Flash | 模组标称 2 MB / 实测 4 MB（固件按 2 MB 配置） |
| RAM | 400 KB SRAM |
| 灯环 | 24 × WS2812B，GPIO3 |
| 语音模块 | ASRPRO V5.0（4M Flash，720 条词表） |
| 存储 | TF 卡（FAT32，音频文件） |
| 按键 | BOOT（GPIO9） |
| 供电 | USB 5V（建议 ≥1A，语音模块峰值电流较高） |

### 4.2 接口

| 接口 | 用途 | 参数 |
|---|---|---|
| UART1（GPIO1/GPIO0） | ESP32 ↔ ASRPRO | 9600 8N1，V1.1 定长帧 57 字节 |
| RMT（GPIO3） | WS2812 数据 | 800 kHz |
| USB（USB-Serial/JTAG） | 烧录/日志 | 115200 |
| TF 卡（ASRPRO 侧） | 音频播放 | FAT32，48 kbps 单声道 MP3 |

### 4.3 网络

| 项目 | 参数 |
|---|---|
| WiFi | 2.4 GHz，WPA2-PSK |
| 时源 | SNTP（ntp.aliyun.com / ntp.tencent.com） |
| 时区 | IP 定位获取（provider=1，默认 +8） |
| 天气 | Open-Meteo（无 Key） |
| 配网 | BLE 5.0 BluFi |

### 4.4 性能指标

| 指标 | 实测值 |
|---|---|
| 上电到显示 | < 1 秒 |
| 上电到校时完成 | 20~25 秒（含 WiFi + SNTP + 天气） |
| 心跳周期 | 1 秒，RTT 约 195 ms |
| 链路判定 | 连续 3 次超时 → OFFLINE |
| 语音响应延迟 | 识别后 < 1 秒开始播报 |
| 整点报时 | 提示音 2 秒 + 语音 4 段 |

## 5. 交互流程

### 5.1 首次使用

```
上电 → 灯环蓝色呼吸（等待配网）
  → App 搜索 ESPARK-ECLOCK-xxxxxx
  → 下发 WiFi → 灯环黄色（连接中）→ 青色（校时）→ 绿色（成功）
  → 12 秒后播报开机问候
```

### 5.2 日常开机

```
上电 → 读取 NVS → 连 WiFi（3 次重试）→ SNTP → 天气缓存
  → 灯环显示时钟 → 12 秒后问候
```

### 5.3 闹钟设置

```
「小爱同学」→「我在」
「帮我定个闹钟」→「是今天的、明天的、还是每天的？」
「今天的」→「是早上、上午、中午、下午、还是晚上？」
「下午」→「请说是几点几分」
「三点三十分」→「好的，已经帮你设定好闹钟了，今天下午三点三十分的时候叫你一次」
```

## 6. 已知限制

| 限制 | 原因 | 影响 |
|---|---|---|
| 闹钟需分步说 | ASRPRO 整句匹配 | 不能说「今天下午三点的闹钟」 |
| 分钟仅 5 分钟档 | 词表 720 条时间词 | 3:32 无法设置，只能 3:30 |
| 音量 30 以下语音偏小 | 双通路标尺不同（已做 2 倍增益补偿） | 建议 50~80 |
| TF 卡 MP3 与语音不能混音 | 硬件不支持 | 只能顺序播放 |
| 2 MB 分区限制 | 单 app 方案 | 固件上限 1.5 MB |
| 无 RTC 电池 | 硬件设计 | 断电后时间丢失，依赖 WiFi 重校 |

## 8. 参考的成熟产品做法

| 产品 | 借鉴点 |
|---|---|
| 小米智能时钟 | 语音为主交互、整点报时不打扰（短提示音）、断网仍可看时间 |
| 涂鸦智能设备 | 配网状态灯语标准化（呼吸=等待，常亮=成功，红闪=失败） |
| Amazon Echo | 闹钟响铃 3 秒内可语音停止；响铃音量渐强 |
| ESP-BLE-Mesh 示例 | 链路心跳 + 状态机（INIT/LINK/READY/OFFLINE） |

**本产品的取舍**：
- 没有做「响铃渐强」（硬件功放不支持精细调节）
- 没有做「多轮上下文」（ASRPRO 无上下文能力，靠 `g_pending_ask` 模拟）
- 没有做「App 远程控制」（无云端，纯本地）
